# Voice Agent Capabilities - Quick Reference

## 📧 Gmail
- Search, read, and send emails
- Create drafts and manage replies
- Organize with labels and threads
- Batch operations for efficiency

## 📁 Google Drive
- Search and access files across all drives
- Read document contents (Docs, Sheets, PDFs, Office files)
- Upload, update, and manage files
- Share files and manage permissions
- Work with folders and shared drives

## 📅 Google Calendar
- View and search calendar events
- Create, update, and delete events
- Manage multiple calendars
- Handle event invitations and attendees
- Quick add for natural language scheduling

## ✅ Google Tasks
- List and search tasks across all lists
- Create, update, and complete tasks
- Organize with task lists and subtasks
- Set due dates and move tasks
- Clear completed tasks

## 🔍 Custom Search
- Perform web searches with advanced filters
- Search specific sites or domains
- Filter by date, file type, or language
- Safe search options

---
*All capabilities require one-time Google authentication*
